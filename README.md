# fadeinflames — personal portfolio

Персональный сайт Максима Гусева: главная, проекты, резюме, ссылки и страница встречи.

Сайт: https://fadeinflames.github.io/ · Репозиторий: https://github.com/fadeinflames/fadeinflames.github.io

## Запуск

Нужен Node.js 24. Установка зависимостей не требуется.

```sh
npm run build
npm run check
npm run dev
```

Локальный адрес: http://127.0.0.1:4177. После изменения исходников выполнить сборку и обновить браузер.

## Содержание и ограничения

- Профиль, проекты и контакты редактируются в `src/content.mjs`, содержание резюме — в `src/resume.mjs`.
- Текущая роль — SRE Team Lead в RWB, город — Москва.
- Описания трёх проектов основаны на соответствующих публичных репозиториях. Форки не представлены как собственные разработки.
- Резюме основано на документе владельца и его правках от 2026-10-04. Достижения и метрики приведены со слов владельца. Ранние инженерные роли объединены; почта, телефон, зарплата и образование исключены из публичной версии. Исходный документ в репозитории не хранится.
- На главной показаны текущая работа и результаты в RWB, преподавание и участие в программных комитетах; подробности доступны в разделах резюме. Метрики для главной и резюме берутся из общего списка в `src/resume.mjs`, чтобы значения не расходились.
- Запись на встречу: https://cal.com/fadeinflames/30min — ссылка предоставлена владельцем. Кнопка на странице «Встреча» открывает Cal.com, где посетитель выбирает время и подтверждает запись. Слоты не дублируются на сайте.
- Личный контакт: https://t.me/fadeinflames. Telegram-канал: https://t.me/youngmaxnotes. Обе ссылки предоставлены владельцем; остальные контакты будут добавлены позже.

## Устройство

Оригинальная статическая реализация: генератор пяти HTML-страниц, общий CSS и небольшие ES-модули. Структура вдохновлена Magic UI Portfolio, палитра и характер движения — Hamish Williams. Код, фотографии, шрифтовые файлы и проекты авторов референсов не копировались. Аватар загружен из публичного профиля владельца. Manrope и IBM Plex Mono подключаются через Google Fonts.

Статический подход выбран для быстрой загрузки, доступного без JavaScript содержания и свободного переноса на любой статический хостинг. Сервер, база и авторизация посетителя пока не нужны; календарь подключается внешней ссылкой. Навигация содержит реальные страницы, фильтр работает локально.

Анимации отключаются с помощью системной настройки reduced motion или кнопки в нижней навигации. Сфера ограничена 30 fps и останавливается в неактивной вкладке. Никакие аналитические данные посетителей не отправляются. Ошибка копирования ссылки отображает адрес вручную; локальный сервер сообщает код ошибки и request ID без данных пользователя.

## Публикация

GitHub Pages публикует сайт из результата GitHub Actions. Каждый push в `main` запускает сборку, проверку страниц и тесты управления анимацией, затем публикует `dist/`. Pull request запускает только сборку и проверки. Повторную публикацию можно запустить вручную через Actions → Publish portfolio → Run workflow.

В Settings → Pages источником выбран GitHub Actions. Публикация использует стандартный `GITHUB_TOKEN`; отдельные токены и секреты не нужны. Действия GitHub зафиксированы по SHA. Логи сборки и результат публикации доступны во вкладке Actions.

Сайт размещается в корне `fadeinflames.github.io`: пути `/assets/`, `/projects/`, `/resume/`, `/links/` и `/meet/` рассчитаны на этот адрес. Для репозитория с другим именем понадобится поддержка префикса пути.

В репозитории хранятся исходники; `dist/` собирается автоматически и исключён из Git. Первый черновик в Sites сохранён отдельно, его настройки и служебные файлы не входят в этот репозиторий. Основное место дальнейших изменений — этот репозиторий.
